## AsureFishing

Плагин, добавляющий возможность подробной кастомизации предметов, получаемых в результате рыбалки.
Базовая механика рыбалки остаётся неизменной
Для корректного функционирования плагина и выдачи наград требуется плагин **MythicMobs**.

---

## Модули и возможности

- **Таблицы наград (FishingTemplate)**: Награды, получаемые в результате рыбалки, определяются таблицей наград, которая может
задаваться отдельно для каждого региона WorldGuard. В случае отсутствия заданной таблицы используется таблица с названием,
указанным в конфигурационном файле. В таблице указываются возможные награды, условия их получения, биом их получения, скилл
MythicMobs, который срабатывает при их получении, и другие свойства.
- **Наживки (Baits)**: Предметы, которые могут потребоваться для поимки рыбы определённой категории. Наживкой является предмет MythicMobs
с определённым названием или тегом, указанным в конфиг-файле BaitTags.yml.
- **Поимка моба**: С определённым шансом вместо награды игрок может поймать указанного в таблице наград моба MythicMobs.
- **Ограничение AFK-рыбалки (AntiAFK)**: набор функций, ограничивающих возможности AFK-наград за рыбалку. Не позволяет игроку
получать награды за рыбалку, находясь в транспорте или кликая на блок.
- **Теги наживок и наград**: Теги, позволяющие объединить несколько различных наград-предметов одним названием. В таблице наград
вместо перечня наживок или видов наград можно указать напрямую тег. В качестве награды за рыбалку будет выдаваться случайный
предмет, относящийся к тегу.
- **Разбор (разделка) предметов**: Возможность разбирать предметы (разделывать рыбу), обладающие определённым компонентом PersistentDataContainer.
Инструменты для разбора указываются в основном конфигурационном файле. Сами предметы для разбора, как правило, настраиваются
через конфиги предметов MythicMobs.

## Сборка

Для компиляции требуется JDK 25 или выше.\
Чтобы запустить сборку, скопируйте проект и запустите сборку через `gradle build`.\
Для одной из зависимостей требуется наличие локального артефакта плагина AsureLib (VineriumLib). Путь до артефакта должен
выглядеть следующим образом относительно папки проекта: `../VineriumLib/build/libs/VineriumLib-1.0-SNAPSHOT.jar`.\
Скомпилированный артефакт будет находиться в папке `build/libs/`.

## Поддержка

Данный плагин разрабатывался для конкретного проекта. Многие возможности плагина были созданы с целью закрыть определённую нишу в
контенте, и могут являться рудиментарными для остальных проектов. При необходимости каждую конкретную функцию плагина можно отключить или перенастроить.

В связи с предназначением плагина услуги по его поддержке предоставляются только в рамках оригинального проекта. Для получения
поддержки (исправление багов, добавление возможностей) в рамках стороннего проекта, вы можете обратиться к автору плагина и оформить заказ консультации.
